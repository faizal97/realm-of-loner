Test build. On Android, turn on Settings → Beta updates; in a browser, play it on the beta page.

**Highlights**
- Added **keybinds**: keys 1–9 fire your action bar, and you can set your own.
- Group runs and raids now have tabs: **Party**, **Next pull** and **Plan**, so nothing hides below the raid.
- On Android, every ability now buzzes, and the screen stays on during fights.
- Guilds for level 60: raiding and PvP guilds on both sides, a **Realm ranking**, and the **Crestbearer** title.

**New Content**
- Added a new main menu theme while **The Notes Come Due** is on: **The Coronation Call**.
- Added raiding guilds to the Accord (**Crimson Vanguard**, **Knights of Ambermoor**) and the Krugar (**Dust Eaters**), and a PvP guild to each side. Raiding guilds ask for level 60.
- Added **Realm ranking** under **Social → Guild**: every guild on the realm, both sides, ranked by raid progress.
- Added **Crestbearer**: clear the newest raid on Hard while it is still the newest. It earns the title **the Crestbearer**.

**Interface**
- Added **keybinds**: keys 1–9 fire the first nine action bar buttons. Set your own in **Hero → Abilities → Arrange action bar → Set key**.
- Each button shows its key once you've pressed one. Keys stay with the button's place, not the ability.
- Group runs and raids now keep the run's name, progress, clock and **Ready** / **Pull** on top, with tabs under them: **Party**, **Next pull** (**Enemies** in a fight) and **Plan** (pace and boss plan).
- A run tab gets a dot when something there needs you, like a boss next with no **Boss plan**.
- The place name now shows the region too: **Halden Vale · Ambermoor**, the same name the Map uses.
- The guild list now puts the guilds that fit your level first, and each guild shows how far it has got in raids.
- Added **Settings → Buzz** (Android): a short buzz on each ability, a double buzz for a red bar.

**Bug Fixes**
- Fixed the Android app never buzzing, even when dragging buttons in **Arrange action bar**.
- Fixed the Android screen dimming and locking during long fights and raid pulls. It now stays on in fights and group runs only.
